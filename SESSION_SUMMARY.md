## 8. `is_enabled()` vs `has_database()` gating bug (found while investigating "updated source file not showing up")
In `router/collections.py`, three purely-Postgres operations (`list_collections`, `delete_collection`'s DB delete, `list_collection_files`) were gated on `supabase_storage.is_enabled()` (S3 credentials!) instead of `has_database()` (DATABASE_URL) — the actual DB calls have nothing to do with S3. In any deployment with a DB but no S3 creds configured, this would make real collections silently invisible/undeletable. Fixed all 3 spots in both `hf-doculens-api` and `pdf-reader`. (Line 220's S3-signed-URL branch correctly stays on `is_enabled()` — that one genuinely needs S3.)
